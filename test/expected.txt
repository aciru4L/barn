barn: the package manager for Goose

usage: barn <command> [arguments] [options]

commands:
  hatch <name>      create a project
  install [dir]     install the project's eggs into .barn/
  add <egg>...      add dependencies
  remove <egg>...   remove dependencies
  upgrade [egg]...  upgrade dependencies to their newest compatible releases
  verify [dir]      check .barn/ against barn.json and ~/.barn/eggs
  build [dir]       check the eggs, then build the project with goose
  run [dir]         check the eggs, then run the project with goose

  --force           install, add, remove, upgrade: replace edited or changed eggs
  --release         lay: tag the commit as a release, then offer to push the tag
  --check           lay: only check the egg and list what it would hold
  --flat            inspect: list the eggs instead of the tree
  -- ...            build: goose's options; run, test: the program's arguments

environment:

usage: barn lay [dir] [--release [-y] | --check]

Puts the egg into ~/.barn/eggs as a new snapshot. With --release,
in a git repository with nothing left to commit, it tags the commit
v<version>, stores that release and asks before pushing the tag to
origin. --check runs the same checks and lists the files the egg
would hold, without laying it.

usage: barn run [dir] [-- program arguments...]

Checks that .barn/ holds what barn.json asks for, unedited,
then runs the project's main file with goose run.

Checks that .barn/ holds what barn.json asks for, unedited,
then runs the project's test file (test/main_test.goose unless
barn.json sets test) with goose run. A test fails by exiting with
a status other than 0.
